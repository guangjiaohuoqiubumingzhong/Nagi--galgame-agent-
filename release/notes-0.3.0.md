# Nagi 0.3.0

Windows x64 便携版。本版集中修复桌面启动、目录选择、任务恢复和游戏部署问题，并将头像与快捷方式图标纳入发布校验。

## 下载和启动

- 普通 Windows 用户下载 **Nagi-0.3.0-windows-x64.zip**，完整解压到可写目录，双击 **Start Nagi.vbs**。
- 不需要预装 Python；若系统禁用 VBScript，可改用 **Start Nagi.cmd**。
- 开发者可选择 **Nagi-0.3.0-source.zip**；它不包含便携运行时。
- **SHA256SUMS.txt** 用于校验附件。不要把 GitHub 自动生成的 Source code 压缩包当作便携版。

## 本版内容

- 目录选择窗口若不能正常显示会自动取消并给出可读提示，不再长期占用后续选择操作。
- 重复启动会识别当前 Nagi 页面，避免无意义地打开多个浏览器页面。
- YU-RIS 479 部署改为使用本次提取时记录的游戏目录、脚本包和启动程序，复制完整运行资源并排除原存档目录，不再绑定单一作品文件名。
- 强化移动安装后的可玩版修复：更新启动、区域设置组件和版本入口，同时保留游戏文件与已有存档。
- 五类引擎均可使用统一的保存目录、任务恢复、部分/全文翻译和测试版/正式版独立副本流程。
- Windows 便携包附带 `assets/nagi-shortcut-icon.ico` 与 PNG 原图；网页 PNG 头像继续随程序提供，三项资源都会在便携验证中检查。

## 使用前须知

程序不包含 API 账户或密钥、Locale Emulator、语义检索模型、游戏资源、译文或存档。请配置自己的 API 服务，并自行确认费用及游戏处理权限。

作品自定义脚本方言、加密 XP3、字体插件及不同发行版本仍可能需要单独适配。具体支持边界和部署条件请阅读包内 `docs/QUICKSTART.md` 与 `docs/REFERENCE.md`。素材及第三方组件的授权范围见 `THIRD_PARTY_NOTICES.md`。

发布流程会运行离线回归测试，验证中文及空格路径下的便携启动与退出，并在公开前下载校验全部上传附件。
