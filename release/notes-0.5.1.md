# Nagi 0.5.1

Windows x64 便携版：混合检索与路线约束更新。

## 下载和启动

- 下载 **Nagi-0.5.1-windows-x64.zip**，完整解压后双击 **Nagi.exe**，无需预装 Python。
- 使用 **SHA256SUMS.txt** 校验附件。程序不附带 API 密钥、游戏、Locale Emulator 或语义检索模型。

## 更新内容

- 五类引擎新翻译任务支持 BM25 + 本地 multilingual-E5 混合检索，使用 RRF 融合并在本地重排模型可用时进行重排。
- 检索始终限制在剧情控制流确认的必经前文；沿用批次上下文预算、向量缓存和修补翻译流程。
- 超出神经模型输入预算的整条记录仍可通过 BM25 检索，不截断原文。
- 旧翻译任务保留原检索方式和 API 回执；模型或策略变化后需新建任务，不自动重译已有付费结果。
- 新增混合检索、恢复、缓存和五类引擎证据边界测试。

缺少本地 E5 模型时会显示 BM25 降级状态；模型需由用户主动下载，翻译过程中不会自动下载。

## 发布验证

发布流程运行离线与前端测试，构建便携包并验证中文及空格路径、独立运行时、启动退出和逐文件哈希；上传附件后重新下载校验。
