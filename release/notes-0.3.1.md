# Nagi 0.3.1

Windows x64 便携版。本补丁将启动方式收敛为一个清晰的应用入口，并为它嵌入新的 Nagi 图标。

## 下载和启动

- 普通 Windows 用户下载 **Nagi-0.3.1-windows-x64.zip**，完整解压到可写目录。
- 双击根目录中唯一的启动入口 **Nagi.exe**。不需要预装 Python。
- 旧版的 **Start Nagi.vbs** 与 **Start Nagi.cmd** 已从便携包移除。
- **SHA256SUMS.txt** 用于校验附件。不要把 GitHub 自动生成的 Source code 压缩包当作便携版。

## 本版内容

- 新增无控制台窗口的 **Nagi.exe**，名称固定为 Nagi，并沿用原有的服务身份、重复启动与错误提示逻辑。
- **Nagi.exe** 嵌入由用户提供参考图制作的多尺寸 Windows 图标，在常见资源管理器尺寸下均有对应图层。
- 便携包继续保留网页头像，并在 `assets` 目录附带应用图标的 PNG 原图与 ICO 文件。
- **Stop Nagi.cmd** 改为通过同一个 Nagi 入口安全停止服务；数据目录选择功能保持不变。

## 验证

发布流程会直接运行移动到中文及空格路径后的 **Nagi.exe**，检查嵌入图标、旧入口移除、离线首次启动、重复启动、网页资源、逐文件哈希和安全退出。全部附件上传后还会重新下载并核对 SHA-256，再公开发行。
