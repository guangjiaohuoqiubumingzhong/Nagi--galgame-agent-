# Nagi 0.3.5

Windows x64 便携版。本版包含当前工作区的部署与模型服务稳定性修复，并让小尺寸应用图标更醒目。

## 下载和启动

- 普通 Windows 用户下载 **Nagi-0.3.5-windows-x64.zip**，完整解压到可写目录。
- 双击根目录中的唯一启动入口 **Nagi.exe**。不需要预装 Python。
- **SHA256SUMS.txt** 用于校验附件；不要把 GitHub 自动生成的 Source code 压缩包当作便携版。

## 本版内容

- 放大 Nagi 应用图标中的人物主体，并重新生成 16、24、32、48、64、128 与 256 像素图层；资源管理器列表中的图标更容易辨认。
- 保留便携部署目录对 `locale_support.py` 的路径加载修复，避免独立游戏启动时出现模块缺失。
- 模型接口遇到 HTTP 429/5xx、网络中断或无效 JSON 时采用渐进退避重试，并保留已经完成的翻译批次。
- 便携版继续只使用 **Nagi.exe** 启动；旧的两个 Start Nagi 脚本不会进入便携包。

## 验证

发布流程会运行完整离线与前端测试，重新构建 Windows x64 便携包，再把程序移动到包含中文及空格的目录中启动。验收覆盖嵌入图标、部署依赖、重复启动、网页资源、逐文件 SHA-256 和安全退出；所有附件上传后会重新下载并再次校验。
