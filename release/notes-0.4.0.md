# Nagi 0.4.0

Windows x64 便携版。本版把五类视觉小说引擎统一到工作台流程，并新增针对已有全文结果的查缺补漏。

## 下载和启动

- 普通 Windows 用户下载 **Nagi-0.4.0-windows-x64.zip**，完整解压到可写目录。
- 双击根目录中的唯一启动入口 **Nagi.exe**。不需要预装 Python。
- **SHA256SUMS.txt** 用于校验附件；不要把 GitHub 自动生成的 Source code 压缩包当作便携版。
- 程序不附带 API 账户、密钥、游戏、Locale Emulator、语义检索模型或翻译结果。

## 本版内容

- KiriKiri/KAG、Ren'Py 与 TyranoScript 现可在工作台完成资源提取、API 翻译和独立汉化副本部署。
- 新增“查缺补漏”，从已有全文结果中选出仍像日文原文的内容，仅重译选中条目，不重复翻译已经完成的中文。
- 修补任务支持中断恢复并记录独立计划、结果与历史；合并成功后仍保持全文结果的范围和部署入口。
- YU-RIS、KiriKiri、Ren'Py 与 TyranoScript 支持查缺补漏；QLIE 保留专用翻译与部署路径。
- 部署继续保护原游戏和存档，并拒绝控制标记变化、仅编译 Ren'Py 脚本以及未适配的加密或自定义格式。
- 保留 0.3.5 的唯一 `Nagi.exe` 启动入口、嵌入图标、部署依赖修复和模型请求重试。

## 验证

发布流程会运行完整离线与前端测试，重新构建源码、wheel 和 Windows x64 便携包，再把便携程序移动到包含中文及空格的目录中启动。验收覆盖独立 Python、五类引擎工作流、查缺补漏恢复、部署安全、应用图标、重复启动、网页资源、逐文件 SHA-256 和安全退出；所有附件上传后会重新下载并再次校验。
