# Nagi 0.5.0

Windows x64 便携版：路线分析与 RAG 上下文更新。

## 下载和启动

- 下载 **Nagi-0.5.0-windows-x64.zip**，完整解压后双击 **Nagi.exe**，无需预装 Python。
- 使用 **SHA256SUMS.txt** 校验附件。程序不附带 API 密钥、游戏、Locale Emulator 或语义检索模型。

## 更新内容

- QLIE、YU-RIS 479、Ren’Py、KiriKiri 和 TyranoScript 新任务使用静态控制流分析，区分可能经过和所有路径必经的前文。
- RAG 仅注入必经前文，支持跨脚本证据，并排除互斥分支、当前批次和重复证据；未知指令或分析不完整时保守处理。
- QLIE 上下文缓存升级；其他四类引擎使用本地 BM25 路线证据，接入重试拆分和查缺补漏。
- 既有翻译计划及回执继续兼容，不自动重译已有付费结果。
- 新增 `translate analyze-routes` 命令，便携包附带路线分析说明。

静态分析基于已支持的语法，不读取玩家存档或选项记录，不代表玩家实际路线；加密、动态或未适配控制语法仍有限制。

## 发布验证

发布流程运行离线与前端测试，构建便携包并验证中文及空格路径、独立运行时、启动退出和逐文件哈希；上传附件后重新下载校验。
